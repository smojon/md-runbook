# Line by line

- **Hover a command** (cells with two or more): `▶ Run line` runs it, `☐ Check` checks it, with a
  plain click; **Run N checked lines** under the cell (or **Run Checked Lines** in the dropdown
  next to the cell's run button) runs the checked ones.
- **The dropdown** also has **Run Lines One by One** (each command in turn, stopping at the first
  that fails) and **Step Through Lines** (pause before each line, like a debugger: `F10` next,
  `F5` continue, `Shift+F5` stop).
- **Select text** in a cell and **Run Selection** (dropdown, right-click, or `Ctrl+Alt+Enter`)
  runs exactly that.
- **Breakpoints:** click the margin left of a line for a red dot; running the cell then pauses
  there.

`cd` and variables carry over from one line to the next.

Try it on section 13 of the sample runbook (**md-runbook: Open Sample Runbook**).
