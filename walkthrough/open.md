# Open a runbook

A runbook is an ordinary Markdown file. **Open as Runbook** (right-click a `.md` file, or the
notebook icon in the editor title bar) shows each fenced `bash`, `pwsh` or `cmd` block as a cell
you can run. Everything else stays Markdown.

The sample opens as an untitled runbook: nothing is written until you save it, and none of its
cells change your machine.
